# versions

Repository to host public version metadata for Your Script resources.

Each resource has a dedicated JSON file named after the FiveM resource name from `fxmanifest.lua`.

```text
ys_inventory.json
ys_clotheshop.json
ys_thumbnailgen.json
ys_clothesfix.json
```

Version files are intentionally small and public so resources can check updates without exposing private source code.
